# 누적 개발 튜토리얼: 선박 배관 3D 시각화

## 배경과 목표 (STEP 01)
- **문제 인식:** 기존 2D 도면/데이터와 단순 3D 도형만으로는 복잡한 배관의 연결 구조를 한눈에 파악하기 어려움. 실제 현장 불편의 정량적 효과나 사고율은 아직 확보하지 않았으며, 현재는 교육용 문제 가설임.
- **개발 목표:** 배관의 공간 경로와 연결 관계를 쉽게 확인하는 3D 시각화 프로토타입 제작. 제작용 CAD 인증 또는 실선 안전 검증은 대상 아님.

## 기술 선정 (STEP 02)
- Unity 2022.3: 3D Scene 표시와 UI 확장을 위해 사용.
- Unity-MCP / RQL / Unity-AI-Splines 소스 검토: AI 기반 경로 제어 인터페이스 설계 참고. 현재 생성기 자체는 Splines 없이 Vector3[] 경로를 사용하며, MCP 직접 호출은 구현 전.
- Procedural Mesh: 원통 몇 개를 이어 붙이는 대신, 경로를 따라 중공 표면을 생성하기 위해 선택.
- 1 Unity unit = 1m. 원본 CAD 좌표 입력은 아직 없음.

## 첫 번째 시각화 (STEP 03~04)
- 구현 코드: `MarinePipeGeometry.Fillet`, `SweepHollow`, `MarinePipeSceneBuilder.BuildDemo`, JSON 가져오기.
- 구성: 3층 랙, 여러 계통의 고밀도 배관, 구조물, 기본 펌프 스키드, 플랜지·밸브 모형.
- 확인된 증거: 사용자가 제공한 Unity Scene 이미지에서 다수의 배관과 구조 프레임이 표시됨.
- 남은 문제: 배관들이 많지만 실제 장비-밸브-헤더-분기관 접속이 명확하지 않음. 연결 관계를 데이터로 검증하지 않았음.

## 연결식 배관 데모 (STEP 05, 이번 단계)
### 왜 수정했나?
- 배관이 겹쳐 보이기만 해서는 어디에서 시작해 어디로 연결되는지 설명하기 어려웠기 때문.
### 무엇을 만들었나?
- `MarineConnectedSystemBuilder.cs`를 추가.
- 흡입구 → 흡입밸브 → 펌프(P-101) → 토출 배관 → 헤더 → 3개의 분기관 → 소비 설비의 연결 경로 구성.
- 배관 ID(`SW-*`, `HDR-*`, `BR-*`) 및 장비 식별자(`XV-*`, `P-101`, `TEE_*`)를 Hierarchy 이름에 표시.
- 기존 중공 Mesh 생성기 재사용. 플랜지 볼트와 밸브 핸드휠의 기본 형상 추가.
- 노드 ID별 연결점 좌표 일치(허용 오차 0.001m)와 각 소비 지점까지의 유향 경로 존재 여부를 코드로 검사.
### 사용법
1. 기존 `Assets/MarinePipe` 소스를 백업.
2. ZIP의 `Assets/MarinePipe`를 프로젝트의 `Assets` 아래에 병합.
3. Unity Editor 메뉴: `Tools → Marine Pipe → 04 - Build Connected Pump Header Demo`.
4. Hierarchy에서 `MARINE_CONNECTED_SYSTEM_V2`를 펼쳐 `SW-*`, `HDR-*`, `BR-*`, `XV-*`, `P-101` 확인.
5. Console의 `V2 connectivity check` 결과 확인. Scene 저장: `Ctrl+S`.
6. 기존 V1 오브젝트는 삭제하지 않고 비활성화됨. 다시 비교하려면 `MARINE_PIPE_DEMO`를 활성화하고 V2를 숨김.
### 검증 기준과 결과 구분
- **코드 수준 판정:** 같은 노드 ID의 좌표 차이 <= 0.001m; 길이 0인 연결 없음; 흡입구에서 소비 지점 3개에 도달 가능.
- **테스트 예정:** Unity 2022.3 컴파일 성공 여부, V2 Scene 생성, 콘솔 PASS, 노즐-배관-플랜지 접속 육안 확인, 엘보 손상 여부.
- **미구현:** 실제 유체 흐름/압력, Tee 불리언 결합, ISO 규격 치수 검증, 파이프-부품 사이의 실제 구멍 절단, 간섭 검사.
- **중요:** `NRV` 표시는 시각적 체크밸브 자리 표시자이고 역류 방지 기능을 물리적으로 시뮬레이션하지 않음.
### 변경 사항
| 단계 | 이전 | 변경 | 의도 |
|---|---|---|---|
| 배관 구성 | 병렬 라인 중심의 고밀도 배관 랙 | 장비에서 헤더로 연결되는 명시적 경로 추가 | 계통 이해 가능성 향상 |

| 부품 | 기본 실린더 | 볼트 플랜지 및 테두리/스포크형 핸드휠 | 부품 인지성 향상 |
